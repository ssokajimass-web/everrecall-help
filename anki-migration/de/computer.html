Anki Desktop

1. Karten als Textdatei exportieren

Öffnen Sie in Anki „Datei" → „Exportieren" und wählen Sie als Exportformat „Karten als Klartext" (Cards in Plain Text). Dieses Format lässt sich von EverRecall am einfachsten einlesen.

Nachdem Sie das Kartenstapel ausgewählt haben, prüfen Sie unbedingt die folgenden zwei Schalter.

⚠️ Beim Exportieren immer diese zwei Schalter prüfen

  • „Mediendateien einschließen" → AUS

Audio- und Bilddateien werden von EverRecall nicht importiert, sie würden die Datei nur unnötig vergrößern.

  • „Ältere Anki-Versionen unterstützen" → AN

Ohne diese Einstellung kann EverRecall die Datei möglicherweise nicht korrekt einlesen.

Auch beim Export als Anki-Paket (.apkg / .colpkg) finden Sie dieselben zwei Schalter auf demselben Bildschirm. Es gilt dieselbe Regel: Medien AUS, Unterstützung älterer Versionen AN.

2. Datei an Ihr iPhone senden

Senden Sie die exportierte Datei (.txt oder .apkg) an Ihr iPhone oder iPad.

  • Wenn Sie einen Mac verwenden: Am einfachsten geht es per AirDrop. Wählen Sie die exportierte Datei aus und tippen Sie im Teilen-Menü auf AirDrop.
  • Wenn Sie Windows verwenden: Da AirDrop hier nicht verfügbar ist, legen Sie die Datei in iCloud Drive ab oder senden Sie sie sich selbst per E-Mail. Auf dem iPhone können Sie die Datei dann über die Dateien-App oder den E-Mail-Anhang öffnen.

3. Mit EverRecall öffnen

Tippen und halten Sie die Datei auf Ihrem iPhone oder iPad (oder tippen Sie auf die Teilen-Schaltfläche) und wählen Sie im Teilen-Menü „In EverRecall öffnen". Sie gelangen damit direkt zum Import-Bildschirm von EverRecall.

Was nicht übernommen wird

Einige Dinge werden bei Anki nicht übernommen. Bitte beachten Sie dies im Voraus.

  • Audio- und Bilddateien (EverRecall importiert nur textbasierte Karten)
  • Lernverlauf und Wiederholungsintervalle (Ihre Trefferquote und die nächsten Wiederholungstermine aus Anki werden nicht übernommen – das Lernen beginnt nach dem Import in EverRecall von vorn)
  • Karten ohne Text (Karten, die nur Audio, nur Bilder oder Bildverdeckungen enthalten, haben keine Textinformationen und werden daher nicht importiert)

Automatischer iCloud-Ordner-Import

Legen Sie .txt- oder .md-Dateien im Ordner iCloud Drive → EverRecall (in der Dateien-App) ab. EverRecall durchsucht diesen Ordner automatisch jedes Mal, wenn Sie die App öffnen, und fügt nur die neu hinzugefügten Dateien als Karten hinzu.

  • Dies ist ein Einwegvorgang. Wenn Sie Karten in EverRecall löschen, werden die Dateien im iCloud-Ordner nicht automatisch gelöscht.
  • Bereits importierte Dateien werden automatisch in einen Unterordner „Verarbeitet" innerhalb desselben Ordners verschoben, sodass Sie auf einen Blick sehen können, was bereits importiert wurde.
  • CSV-Dateien und Anki-Pakete (.apkg / .colpkg) werden vom automatischen iCloud-Ordner-Import nicht erfasst – nur Text- (.txt) und Markdown-Dateien (.md) werden unterstützt. Importieren Sie CSV-Dateien oder Anki-Pakete stattdessen über den Import-Bildschirm oder das Teilen-Menü.
