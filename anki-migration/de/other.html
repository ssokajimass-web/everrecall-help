Falls keiner der oben genannten Fälle zutrifft oder Sie nur wissen möchten, welche Dateiformate unterstützt werden, finden Sie hier die vollständige Liste. EverRecall akzeptiert:

ChatGPT oder Gemini die Karten schreiben lassen

Tippen Sie auf dem Import-Bildschirm auf „Prompt für KI kopieren". Dadurch wird eine Anfrage kopiert, die mit Ihren aktuellen Trennzeichen-Einstellungen formatiert ist. Fügen Sie sie zusammen mit dem Text (oder Thema), aus dem Karten werden sollen, in ChatGPT oder Gemini ein.

1. Tippen Sie auf dem Import-Bildschirm auf „Prompt für KI kopieren" 2. Fügen Sie ihn in ChatGPT oder Gemini ein, fügen Sie dann den Text oder das Thema ein (oder tippen Sie ihn), aus dem Karten entstehen sollen, und senden Sie die Nachricht 3. Verwenden Sie die Kopieren-Schaltfläche im Code-Block der Antwort, um das Ergebnis zu kopieren 4. Fügen Sie es in den Import-Bildschirm von EverRecall ein, oder teilen Sie den ausgewählten Text und wählen Sie „An EverRecall senden" (siehe „Die zwei Funktionen des Teilen-Menüs" weiter unten)

Die gemeinsame Trennzeichen-Regel (Einfügen, geteilter Text, der iCloud-Ordner und Textdateien)

Einfügen, das Teilen von Text über das Teilen-Menü, der iCloud-Ordner und Textdateien (.txt / .md) teilen Karten alle anhand derselben Trennzeichen-Einstellungen auf. Sie können diese jederzeit im Bereich „Trennzeichen" des Import-Bildschirms ändern.

  • Standard: Karten werden durch eine Zeile getrennt, die nur „---" enthält, und Vorder-/Rückseite einer Karte werden durch eine Zeile getrennt, die nur „==" enthält
  • Ein Symbol zählt nur dann als Trennzeichen, wenn die gesamte Zeile nur aus diesem Symbol besteht — ein Symbol innerhalb eines Satzes (z. B. „A---B") führt nie zu einer Trennung
  • Um eine Gruppe von Karten mit Buchtitel und Autor zu kennzeichnen, verwenden Sie Zeilen wie @@title: Buchtitel und @@author: Autorenname (dieses Symbol lässt sich in den Einstellungen ebenfalls ändern)

Die zwei Funktionen des Teilen-Menüs

Das Teilen-Menü auf iPhone/iPad bietet zwei unterschiedliche EverRecall-Funktionen — hier der Unterschied:

  • „In EverRecall öffnen" (beim Teilen einer Datei): öffnet den Import-Bildschirm von EverRecall, sodass Sie die Karten vor dem Hinzufügen überprüfen können
  • „An EverRecall senden" (beim Teilen von ausgewähltem Text): fügt ihn direkt dem Posteingang hinzu, ohne Bestätigungsbildschirm. Sie können die Karten danach weiterhin bearbeiten oder löschen

CSV (.csv)

Die erste Spalte wird zur Vorderseite, die zweite Spalte wird zur Rückseite. (Dies ist ein Tabellenformat und wird von den obigen Trennzeichen-Einstellungen nicht beeinflusst.)

Anki-Paket (.apkg / .colpkg)

Sie können eine von Anki exportierte Paketdatei direkt importieren. Sie müssen beim Export keine Einstellungen ändern.

Automatischer Import über den iCloud-Ordner

Legen Sie einfach .txt- / .md-Dateien in einen iCloud-Ordner – sie werden automatisch erkannt, nach derselben oben beschriebenen Trennzeichen-Regel. Details dazu finden Sie auf der nächsten Seite.

Was nicht übernommen wird

Einige Dinge werden bei Anki nicht übernommen. Bitte beachten Sie dies im Voraus.

  • Audio- und Bilddateien (EverRecall importiert nur textbasierte Karten)
  • Lernverlauf und Wiederholungsintervalle (Ihre Trefferquote und die nächsten Wiederholungstermine aus Anki werden nicht übernommen – das Lernen beginnt nach dem Import in EverRecall von vorn)
  • Karten ohne Text (Karten, die nur Audio, nur Bilder oder Bildverdeckungen enthalten, haben keine Textinformationen und werden daher nicht importiert)

Automatischer iCloud-Ordner-Import

Legen Sie .txt- oder .md-Dateien im Ordner iCloud Drive → EverRecall (in der Dateien-App) ab. EverRecall durchsucht diesen Ordner automatisch jedes Mal, wenn Sie die App öffnen, und fügt nur die neu hinzugefügten Dateien als Karten hinzu.

  • Dies ist ein Einwegvorgang. Wenn Sie Karten in EverRecall löschen, werden die Dateien im iCloud-Ordner nicht automatisch gelöscht.
  • Bereits importierte Dateien werden automatisch in einen Unterordner „Verarbeitet" innerhalb desselben Ordners verschoben, sodass Sie auf einen Blick sehen können, was bereits importiert wurde.
  • CSV-Dateien und Anki-Pakete (.apkg / .colpkg) werden vom automatischen iCloud-Ordner-Import nicht erfasst – nur Text- (.txt) und Markdown-Dateien (.md) werden unterstützt. Importieren Sie CSV-Dateien oder Anki-Pakete stattdessen über den Import-Bildschirm oder das Teilen-Menü.
