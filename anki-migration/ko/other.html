기타

위 4가지에 해당하지 않거나 파일 형식만 알고 싶다면 이 항목을 참고하세요. EverRecall은 다음 형식을 지원합니다.

ChatGPT나 Gemini에게 카드 작성 맡기기

가져오기 화면에서 "AI에게 보낼 문구 복사"를 탭하세요. 현재 구분 기호 설정에 맞춰 만들어진 요청 문구가 복사됩니다. 카드로 만들고 싶은 텍스트(또는 주제)와 함께 ChatGPT나 Gemini에 붙여넣으세요.

1. 가져오기 화면에서 "AI에게 보낼 문구 복사"를 탭 2. ChatGPT나 Gemini에 붙여넣은 뒤, 카드로 만들고 싶은 텍스트나 주제를 붙여넣거나(또는 입력하고) 전송 3. 답변의 코드 블록에 있는 복사 버튼으로 결과를 복사 4. EverRecall의 가져오기 화면에 붙여넣거나, 선택한 텍스트를 공유해서 "EverRecall로 보내기"를 선택 (아래 "공유 시트의 두 가지 기능" 참고)

공통 구분 기호 규칙(붙여넣기, 텍스트 공유, iCloud 폴더, 텍스트 파일)

붙여넣기, 공유 시트를 통한 텍스트 공유, iCloud 폴더, 텍스트 파일(.txt / .md) 모두 동일한 구분 기호 설정으로 카드를 나눕니다. 설정은 가져오기 화면의 "구분 기호" 항목에서 언제든지 바꿀 수 있습니다.

  • 기본값: 카드와 카드 사이는 "---"만 있는 줄로 구분하고, 카드의 앞면과 뒷면은 "=="만 있는 줄로 구분합니다
  • 기호는 그 줄 전체가 해당 기호만으로 이루어져 있을 때만 구분 기호로 인식됩니다. 문장 중간에 기호가 있어도(예: "A---B") 그 부분에서는 나뉘지 않습니다
  • 책 제목과 저자를 한꺼번에 지정하려면 @@title: 책 제목, @@author: 저자 이름 형식의 줄을 사용하세요(이 기호도 설정에서 바꿀 수 있습니다)

공유 시트의 두 가지 기능

iPhone·iPad의 공유 시트에는 EverRecall과 관련된 기능이 두 가지 있습니다. 차이는 다음과 같습니다.

  • "EverRecall에서 열기"(파일을 공유했을 때): EverRecall의 가져오기 화면이 열려 카드를 추가하기 전에 내용을 확인할 수 있습니다
  • "EverRecall로 보내기"(선택한 텍스트를 공유했을 때): 확인 화면 없이 바로 받은함에 추가됩니다. 이후에도 카드를 수정하거나 삭제할 수 있습니다

CSV(.csv)

첫 번째 열이 앞면, 두 번째 열이 뒷면이 됩니다. (표 형식 파일이며, 위의 구분 기호 설정과는 무관합니다.)

Anki 패키지(.apkg / .colpkg)

Anki에서 내보낸 패키지 파일을 그대로 가져올 수 있습니다. 내보낼 때 설정을 따로 바꿀 필요가 없습니다.

iCloud 폴더 자동 가져오기

.txt / .md 파일을 iCloud 폴더에 넣기만 하면 위에서 설명한 것과 같은 구분 기호 규칙으로 자동으로 가져옵니다. 자세한 내용은 다음 페이지를 참고하세요.

이전되지 않는 항목

Anki에서 넘어오지 않는 항목이 있습니다. 미리 알아두세요.

  • 오디오 파일·이미지 파일 (EverRecall은 텍스트 카드만 가져옵니다)
  • 학습 기록·복습 간격 (Anki에서의 정답률이나 다음 복습일은 이어지지 않습니다. EverRecall에 가져온 시점부터 새로 학습이 시작됩니다)
  • 텍스트가 없는 카드 (오디오 전용·이미지 전용·이미지 오클루전 카드 등 텍스트 정보가 없는 카드는 가져오지 않습니다)

iCloud 폴더 자동 가져오기

"파일" 앱의 iCloud Drive → EverRecall 폴더에 .txt 또는 .md 파일을 넣어두면, 앱을 열 때마다 자동으로 스캔되어 새로 추가된 파일만큼 카드가 늘어납니다.

  • 단방향 방식입니다. EverRecall에서 카드를 삭제해도 iCloud 폴더의 파일은 자동으로 삭제되지 않습니다.
  • 가져오기가 끝난 파일은 같은 폴더 안의 "처리 완료" 폴더로 자동으로 이동합니다. 폴더를 보면 어떤 파일이 이미 가져와졌는지 한눈에 알 수 있습니다.
  • CSV나 Anki 패키지(.apkg / .colpkg)는 iCloud 폴더 자동 가져오기 대상이 아닙니다. 지원되는 것은 텍스트(.txt)와 Markdown(.md)뿐입니다. CSV나 Anki 패키지는 가져오기 화면이나 공유 시트를 통해 가져오세요.
