Anki Bureau

1. Exporter vos cartes au format texte

Dans Anki, ouvrez Fichier → Exporter, puis choisissez « Cartes en texte brut » (Cards in Plain Text) comme format d'exportation. C'est le format le plus facile à importer dans EverRecall.

Une fois le paquet sélectionné, vérifiez impérativement les deux réglages suivants :

⚠️ Deux réglages à vérifier systématiquement avant l'exportation

  • « Inclure les fichiers multimédias » → Désactivé

EverRecall n'importe ni les fichiers audio ni les images ; les inclure ne fait qu'augmenter la taille du fichier inutilement.

  • « Prendre en charge les anciennes versions d'Anki » → Activé

Sans cette option, EverRecall risque de ne pas pouvoir lire le fichier correctement.

Si vous exportez plutôt sous forme de paquet Anki (.apkg / .colpkg), les deux mêmes réglages apparaissent sur cet écran d'exportation. Le principe reste le même : fichiers multimédias désactivés, prise en charge des anciennes versions activée.

2. Envoyer le fichier sur votre iPhone

Transférez le fichier exporté (.txt ou .apkg) vers votre iPhone ou iPad.

  • Si vous utilisez un Mac : AirDrop est la solution la plus simple. Sélectionnez le fichier exporté et choisissez AirDrop dans le menu de partage.
  • Si vous utilisez Windows : AirDrop n'étant pas disponible, placez le fichier dans iCloud Drive ou envoyez-le-vous par e-mail. Vous pourrez ensuite l'ouvrir depuis l'application Fichiers ou depuis la pièce jointe de l'e-mail sur votre iPhone.

3. Ouvrir le fichier avec EverRecall

Une fois le fichier sur votre iPhone ou iPad, effectuez un appui long dessus (ou appuyez sur le bouton de partage), puis choisissez « Ouvrir dans EverRecall » dans la feuille de partage. Vous accédez ainsi directement à l'écran d'importation d'EverRecall.

Ce qui n'est pas transféré

Certains éléments ne sont pas transférés depuis Anki. Merci d'en tenir compte avant de commencer :

  • Fichiers audio et images (EverRecall n'importe que les cartes contenant du texte)
  • Historique d'apprentissage et intervalles de révision (votre taux de réussite et vos prochaines dates de révision dans Anki ne sont pas conservés ; l'apprentissage recommence à zéro dès l'importation des cartes dans EverRecall)
  • Cartes sans texte (les cartes composées uniquement d'audio, uniquement d'images, ou les cartes à occlusion d'image n'ont pas de contenu textuel à importer et sont donc ignorées)

Importation automatique via un dossier iCloud

Déposez des fichiers .txt ou .md dans le dossier iCloud Drive → EverRecall (dans l'application Fichiers) : EverRecall analyse automatiquement ce dossier à chaque ouverture de l'application, en n'ajoutant sous forme de cartes que les fichiers nouvellement déposés.

  • Il s'agit d'un processus à sens unique. Supprimer des cartes dans EverRecall ne supprime pas les fichiers présents dans le dossier iCloud.
  • Une fois un fichier importé, il est automatiquement déplacé dans un sous-dossier « Traités » à l'intérieur du même dossier, ce qui permet de repérer d'un coup d'œil ce qui a déjà été importé.
  • Les fichiers CSV et les paquets Anki (.apkg / .colpkg) ne sont pas pris en charge par l'importation automatique via le dossier iCloud ; seuls les fichiers texte (.txt) et Markdown (.md) le sont. Importez les fichiers CSV ou les paquets Anki via l'écran d'importation ou la feuille de partage.
