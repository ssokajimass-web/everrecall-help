Anki Desktop

1. Export your cards as plain text

In Anki, open File → Export, and choose "Cards in Plain Text" as the export format. This is the format EverRecall can read most easily.

After picking the deck, just export it — you don't need to change any export settings.

The same is true if you export as an Anki package (.apkg / .colpkg) instead. Just export it with the default settings.

2. Send the file to your iPhone

Send the exported file (.txt or .apkg) to your iPhone or iPad.

  • On a Mac: AirDrop is the easiest way. Select the exported file and choose AirDrop from the share menu.
  • On Windows: AirDrop isn't available, so put the file in iCloud Drive, or email it to yourself. You can open it from the Files app or from the email attachment on your iPhone.

3. Open it with EverRecall

Once the file is on your iPhone or iPad, touch and hold it (or tap the share button) and choose "Open in EverRecall" from the share sheet. This takes you straight to EverRecall's import screen.

What doesn't carry over

Some things don't carry over from Anki. Please keep this in mind before you start:

  • Audio and image files (EverRecall only imports text-based cards)
  • Study history and review intervals (your accuracy and next-review dates in Anki are not carried over — learning starts fresh once cards are imported into EverRecall)
  • Cards with no text (audio-only, image-only, and image occlusion cards have no text to import, so they're skipped)

Automatic iCloud folder import

Drop .txt or .md files into the iCloud Drive → EverRecall folder (in the Files app), and EverRecall automatically scans it every time you open the app — adding only the newly placed files as cards.

  • This is a one-way process. Deleting cards inside EverRecall does not delete the files in the iCloud folder.
  • Once a file is imported, it's automatically moved into a "Processed" subfolder inside the same folder, so you can tell at a glance what's already been imported.
  • CSV files and Anki packages (.apkg / .colpkg) are not picked up by automatic iCloud folder import — only text (.txt) and Markdown (.md) files are. Import CSV or Anki packages via the import screen or the share sheet instead.
