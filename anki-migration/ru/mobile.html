В AnkiMobile экспорт и импорт можно полностью выполнить прямо на iPhone — компьютер не нужен.

Шаги

1. На экране списка колод нажмите кнопку в левом нижнем углу (похожа на шестерёнку или значок «⋯»). 2. Выберите «Экспорт». 3. Выберите формат экспорта и экспортируйте файл — менять настройки не нужно.

4. По завершении экспорта автоматически откроется меню общего доступа. Выберите «Открыть в EverRecall», чтобы сразу перейти к экрану импорта.

Все эти 4 шага выполняются полностью на iPhone — компьютер не требуется.

Что не переносится

Некоторые данные не переносятся из Anki. Учтите это перед началом переноса:

  • Аудио- и графические файлы (EverRecall импортирует только текстовые карточки)
  • История занятий и интервалы повторения (процент правильных ответов и даты следующего повторения из Anki не переносятся — после импорта в EverRecall обучение начинается заново)
  • Карточки без текста (карточки только с аудио, только с изображением, а также карточки с окклюзией изображений не содержат текста для импорта, поэтому пропускаются)

Автоматический импорт из папки iCloud

Поместите файлы .txt или .md в папку iCloud Drive → EverRecall (в приложении «Файлы»), и EverRecall будет автоматически сканировать её при каждом запуске приложения, добавляя карточки только из вновь появившихся файлов.

  • Это односторонний процесс. Удаление карточек в EverRecall не удаляет файлы в папке iCloud.
  • После импорта файл автоматически перемещается в подпапку «Processed» («Обработано») внутри той же папки, поэтому вы сразу видите, что уже импортировано.
  • Файлы CSV и пакеты Anki (.apkg / .colpkg) не обрабатываются автоматическим импортом из папки iCloud — поддерживаются только текстовые файлы (.txt) и Markdown (.md). Файлы CSV и пакеты Anki импортируйте через экран импорта или меню общего доступа.
