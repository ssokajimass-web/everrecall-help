让 ChatGPT 或 Gemini 帮你写卡片

在导入界面点按 「复制发给AI的提示词」。这会复制一段按你当前分隔符设置生成的请求文本。将它和你想转换成卡片的文本（或主题）一起粘贴给 ChatGPT 或 Gemini。

1. 在导入界面点按「复制发给AI的提示词」 2. 粘贴到 ChatGPT 或 Gemini 中，再粘贴（或输入）你想生成卡片的文本或主题，然后发送 3. 用回复中代码块上的复制按钮复制结果 4. 粘贴到 EverRecall 的导入界面，或者共享选中的文字并选择「发送到 EverRecall」（参见下方「共享面板的两个功能」）

通用分隔符规则（粘贴、共享文本、iCloud 文件夹、文本文件）

粘贴、通过共享面板发送文本、iCloud 文件夹、文本文件（.txt / .md），这几种方式都使用同一套分隔符设置来拆分卡片。你可以随时在导入界面的「分隔符」栏中修改这些设置。

  • 默认设置：卡片与卡片之间用只包含 「---」 的一行分隔，正面与背面之间用只包含 「==」 的一行分隔
  • 只有整行只有该符号本身时才会被当作分隔符——句子中出现的符号（例如「A---B」）不会造成拆分
  • 如果要给一批卡片统一标注书名和作者，使用 @@title: 书名 和 @@author: 作者名 这样的行（这个符号也可以在设置中修改）

共享面板的两个功能

iPhone、iPad 的共享面板提供两个不同的 EverRecall 功能，区别如下：

  • 「用 EverRecall 打开」（共享文件时）：打开 EverRecall 的导入界面，让你在添加卡片前先确认
  • 「发送到 EverRecall」（共享选中的文字时）：不经过确认画面，直接添加到收件箱。之后仍可以编辑或删除这些卡片

CSV（.csv）

第一列作为正面，第二列作为背面。（这是表格格式，不受上述分隔符设置影响。）

Anki 包（.apkg / .colpkg）

可以直接导入从 Anki 导出的包文件。导出时不需要修改任何设置。

如果还想继承学习记录（复习间隔），请在导出前于 Anki 的导出界面开启 "包含排程信息"。开启该选项导出的文件，在导入 EverRecall 时可以选择"继承"或"重新开始"。未开启该选项导出的文件，会全部作为全新卡片导入。

自动添加到 iCloud 文件夹

只需把 .txt / .md 文件放进 iCloud 文件夹，就会按上述同样的分隔符规则自动识别导入。详情请参阅下一页。

不会迁移的内容

有些内容无法从 Anki 迁移过来，请事先了解。

  • 音频文件、图片文件（EverRecall 只导入文字卡片）
  • 没有文字的卡片（仅有音频、仅有图片、图片遮挡卡等没有文字信息的卡片将不会被导入）

iCloud 文件夹自动导入

只要将 .txt 或 .md 文件放入「文件」App 中的 iCloud Drive → EverRecall 文件夹，每次打开应用时都会自动扫描，仅将新放入的文件转换为卡片。

  • 这是单向的机制。即使在 EverRecall 中删除卡片，iCloud 文件夹中的文件也不会被自动删除。
  • 导入完成的文件会自动移动到同一文件夹下的「已处理」子文件夹中，一目了然地看出哪些已经导入过。
  • CSV 文件和 Anki 包（.apkg / .colpkg）不属于 iCloud 文件夹自动导入的对象，自动导入仅支持文本（.txt）和 Markdown（.md）文件。CSV 或 Anki 包请通过导入界面或共享面板导入。
